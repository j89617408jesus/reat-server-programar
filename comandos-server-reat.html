Guia de Comandos React ⚛️

Copia os comandos abaixo e cola-os no terminal do teu PC real para criares o teu ecossistema profissional.

1. Verificar se tens o Node.js instalado
node -v
2. Criar novo projeto React via Vite (Substitui 'meu-app')
npm create vite@latest meu-app -- --template react
3. Entrar na pasta criada pelo Vite
cd meu-app
4. Instalar as dependências do React
npm install
5. Iniciar o Servidor Local (Para veres o teu código no navegador)
npm run dev
6. Compilar o site para colocar na Internet (Gera a pasta /dist)
npm run build
